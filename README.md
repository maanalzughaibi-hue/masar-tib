# مَسار طِب

نظام ويب يرافق الطبيب في رحلة المريض العلاجية: **التقييم ← التشخيص ← العلاج ← المتابعة**.

## المميزات
- تسجيل دخول وحساب لكل طبيب، وكل طبيب يرى مرضاه فقط (RLS).
- لوحة رئيسية: إحصائيات، متابعات اليوم والمتأخرة، الحالات الحرجة، وتوزيع الحالات على المسار.
- ملفات المرضى مع البحث والتصفية حسب المرحلة.
- ملف المريض: مؤشر مراحل، اقتراح الخطوة التالية، تنبيه الحساسية، والسجل الزمني الكامل.
- تمييز العلامات الحيوية غير الطبيعية تلقائياً، وتحذير عند وصف دواء يتعارض مع حساسية المريض.
- إدارة المتابعات (تمت / لم يحضر / متأخرة) وطباعة تقرير حالة كامل.
